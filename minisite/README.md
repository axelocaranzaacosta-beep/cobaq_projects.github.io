# 🎵 Minisite Musical — Proyecto Escolar

Sitio web escolar dedicado a tres íconos de la música: **Luis Miguel**, **Michael Jackson** y **Måneskin**.

## Estructura de archivos

```
minisite/
├── index.html              ← Página principal (Home)
├── css/
│   └── style.css           ← Estilos globales
├── js/
│   └── carousel.js         ← Lógica del carrusel de videos
├── images/
│   ├── vinyl.svg           ← Disco de vinilo (animación álbumes)
│   └── logo-colegio.png    ← ⚠️ AGREGAR: Logo del Colegio de Bachilleres
└── pages/
    ├── luis-miguel.html
    ├── michael-jackson.html
    └── maneskin.html
```

## Cómo subir a GitHub Pages

1. Crea un repositorio en GitHub (p. ej. `musica-escolar`)
2. Sube todos los archivos respetando la estructura de carpetas
3. Ve a **Settings → Pages**
4. En *Source*, selecciona la rama `main` y la carpeta `/ (root)`
5. Haz clic en **Save**
6. Tu sitio estará disponible en `https://tu-usuario.github.io/musica-escolar/`

## Logo del colegio

Coloca el logo del Colegio de Bachilleres en `images/logo-colegio.png`  
y descomenta la línea en `index.html`:

```html
<!-- <img src="images/logo-colegio.png" alt="Logo"> -->
```
