# 🎵 Minisite Musical — Proyecto Escolar

Sitio web escolar dedicado a tres íconos de la música: **Luis Miguel**, **Michael Jackson** y **Måneskin**.

## Estructura de archivos

```
minisite/
├── index.html              ← Página principal (Home)
├── css/
│   └── style.css           ← Estilos globales
├── js/
│   └── carousel.js         ← Lógica del carrusel de videos
├── images/
│   ├── vinyl.svg          
│   └── logo-colegio.png    
└── pages/
    ├── luis-miguel.html
    ├── michael-jackson.html
    └── maneskin.html
```

## Fuentes de imágenes

Las imágenes de artistas provienen de Wikimedia Commons (licencia libre).  
Las carátulas de álbumes también vienen de Wikimedia y Wikipedia.
